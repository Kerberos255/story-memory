# 剧情记忆 · Story Memory

适用于 SillyTavern 的剧情记忆扩展：自动整理楼层摘要、分层压缩剧情，并维护角色、物品、场景与计划状态；支持历史检索和可选的语义召回。

## 安装

在 **SillyTavern → 扩展 → 安装扩展** 中填写：

```text
https://github.com/Kerberos255/story-memory
```

安装或更新后，扩展会在安全时自动刷新页面；若未生效，可手动刷新。点击输入框上方的「✦ 剧情记忆」打开面板，支持明暗主题。

## 主要功能

- **剧情摘要**：逐楼提取事件与状态，按 L0 → L1 → L2 → L3+ 分层压缩。时间线支持实时搜索，刷新后保留已展开卡片；可查看原文、编辑或删除摘要。
- **整理进度**：全部完成时收起为紧凑状态条，需要时展开；仍有任务、延迟保护或故障时展示详细进度和分类。支持单楼与批量补摘、非阻塞异常通知。
- **人物、物品、场景、计划**：卡片展示关键状态，详情可切换变更记录、人工纠错及合并称呼，切换时保留未保存输入。支持逐字段锁定、改名后的实体合并与撤销；已失效记录供查阅，不注入当前状态。角色支持知情边界与在场记录。
- **记忆检索**：默认提供本地历史与结构化状态检索，无须向量 API。可独立开启 Embedding 和重排；对新增或变化的内容后台增量索引。
- **记忆发送**：摘要默认作为历史背景注入；物品、场景、角色、计划可分别控制是否发送。支持预览实际组成、字符数和由酒馆分词器统计的 Token 数。

## 默认设置

| 选项 | 默认值 |
| --- | --- |
| 自动摘要、摘要成功后自动隐藏 | 开启 |
| 自动摘要延迟 / 最近正文保留 | 各 3 条 AI 回复 |
| 每次 AI 回复结束后自动补摘 | 最多 5 楼 |
| L0 → L1 / L1 → L2 / L2 → L3+ 阈值 | 12 / 6 / 3 |
| L0 最近未压缩摘要保留 | 3 条 |
| 摘要 API | 跟随酒馆主 API |
| 温度 / Think 等级 / 输出上限 | 0 / Auto / 不指定 |
| 网络错误额外即时重试 | 1 次 |
| 记忆发送上限 | 16,000 Tokens |
| 语义检索、重排 | 关闭 |

手动批量补摘不受自动延迟及每轮 5 楼限制。压缩阈值设置为 `0` 可关闭对应层级。

**失败恢复**：网络错误、超时、429 和部分 5xx 响应在即时重试后，可于 30 秒、2 分钟、5 分钟进行有限自动恢复；达到上限或遇到不可自动恢复的错误后暂停该楼层并提醒人工处理。手动重试仍可使用，不会无限请求 API。

## 设置说明

- **摘要 API**：可跟随主 API，也可配置独立 URL、Key 和模型。独立模式不修改主 API。输出上限留空时由服务商决定；遇到模型不支持温度或思考等级时可调整相应设置。
- **提取与注入**：人物、物品、场景、计划的提取和发送分别控制。关闭提取不会删除已保存档案；关闭发送也不会停止提取。记忆超限时优先选取完整条目，预览显示各类的选中和跳过原因；未发送内容仍保存。支持自定义提示词与「预览最终提示词」。
- **向量检索**：Embedding 默认模型 `BAAI/bge-m3`，重排默认模型 `BAAI/bge-reranker-v2-m3`（开关关闭）。需填写兼容接口的 URL、Key；浏览器直连要求服务商允许 CORS。索引缓存在 IndexedDB 中，支持手动更新。
- **高级参数**：摘要 API 可配置额外请求参数及允许的请求标头。认证由对应 API Key 处理，不要在自定义标头中重复填写凭证。

## 使用注意

- **自动隐藏不删除聊天原文**：仅在摘要成功且离开保留窗口后隐藏。关闭自动隐藏后，可在「剧情摘要」页手动恢复此前隐藏的原文。
- 修改、切换回复或删除原文后，相关摘要与检索来源会重新校验。长楼层分段整理可复用已完成片段；分层压缩失败保留原有摘要并提示重试，不保存截断或半成品结果。
- Token 统计依赖当前酒馆分词器，与模型实际计费可能不同。注入位于 Chat History 前端，仍可能受到上下文裁剪。
- 独立 API Key 保存在酒馆扩展设置中，**不要公开分享含配置的备份**。首次使用建议先在测试聊天确认摘要、自动隐藏和记忆发送符合预期。
