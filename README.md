# Story Memory（剧情记忆）

轻量、独立的 SillyTavern 剧情记忆扩展。原生 JavaScript ES Modules 与 CSS，无前端框架或额外后台进程。**v0.1.0 开发版：尚未完成真实 SillyTavern 端到端验收。**

## 安装

在 SillyTavern 的「扩展」→「安装扩展」中输入：

```text
https://github.com/Kerberos255/story-memory
```

安装后刷新酒馆，聊天输入框上方会出现「✦ 剧情记忆」按钮。点击打开居中弹窗。

> 首次安装请在**测试聊天**中验证；不要直接开启自动摘要去批量处理重要的长期聊天。

## 现有功能

- 楼层剧情摘要与待补摘楼层、串行任务队列、有限失败重试、章节与概览总结。
- 物品、场景、人物的结构化变更记录；依据楼层正文与 swipe 指纹检测过期信息。
- 手动输入、纯文本导入及人工记忆编辑／删除（删除操作需要确认）。
- 副 API：通过 SillyTavern Custom API 服务端请求，支持排除请求参数、附加请求体参数和自定义普通请求标头。
- 独立 JSON 摘要指令、手动扩展摘要与章节模板。
- 简化记忆注入与注入预览；可选的 SillyTavern 原生向量检索（后端需要支持和配置）。
- Shadow DOM 隔离的暗金毛玻璃弹窗；关闭时释放弹窗内页面节点。

## 副 API

先在 SillyTavern 自己的 Custom API 连接配置对应密钥。扩展只接收 API 地址、模型 ID 和普通请求参数，**不保存 API 密钥**。如有特殊服务商标头，在「包含请求标头」填写 JSON 对象，例如：

```json
{"x-opencode-session":"your-session-name"}
```

插件不自动添加 OpenCode Go 标头或会话 ID。出于安全考虑，Authorization、Cookie 等认证字段不可通过此配置覆盖；认证应走酒馆原生服务端密钥管理。这里不提供真实凭证示例。

## 当前开发限制

- 此版本为开发预览，尚无实际 SillyTavern 的跨环境安装／视觉验收。
- 自动摘要默认关闭；必须自行设置副 API 才能发起补摘。
- **不自动隐藏原始剧情**。如果原文仍包含在主提示词，主动注入摘要可能出现重复；请先用「注入预览」检查。
- 向量记忆使用 ST 的 `/api/vector` 服务端接口，目前适配 siliconflow 的配置，服务端密钥需要用户自行在 SillyTavern 配置。
- 没有柏宝书数据迁移，也不应同时启用两个摘要插件去处理同一个聊天。
- Google/其它上游内容拒绝不会通过重试绕过。
