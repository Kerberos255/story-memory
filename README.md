# 剧情记忆 · Story Memory

轻量 SillyTavern 剧情记忆扩展：楼层摘要、章节与长期概览，配套物品、场景、角色状态，以及按需向量召回。

## 安装

在 SillyTavern → 扩展 → 安装扩展，输入：

```text
https://github.com/Kerberos255/story-memory
```

刷新酒馆，在输入框上方点击「✦ 剧情记忆」打开弹窗。默认暗色主题，可在右上角切换明亮主题。

## 功能

- **摘要**：按楼层整理剧情和状态变化；按阈值构建可追溯、保留子节点的 L1 阶段总结、L2 二次总结和 L3+ 高层总结。支持分层阈值与保留最近未压缩摘要数。**自动生成的楼层摘要、L1+ 分层总结均可展开编辑或删除**。
- **物品 / 场景 / 角色**：提取剧情中的实际变化，原楼层修改或切换回复后自动判定历史记录是否有效。新摘要附带当前聊天已登记的实体清单，模型可引用稳定的 `entity_id` 更新已有物品、地点或人物，避免仅因名称变化重复登记。已有重复记录可在对应页面展开「合并同一实体的不同称呼」，选定原记录和保留名称后确认合并，也可撤销；**不自动猜测或合并相似名称，不修改原始楼层摘要**。摘要模型收到当前已登记实体清单和稳定 `entity_id`，能在同一物品、地点或人物换称呼时沿用身份；对旧记录里的不同名称可在卡片中手动选择同一实体合并，并支持撤销。仅名称相似不会自动合并，避免误把两件物品或两个人混为一谈。
- **摘要 API**：默认「跟随主 API」，也可选择「独立副 API」。独立模式可在插件内填写 URL、API Key、模型，并通过模型旁的刷新按钮获取模型列表。跟随模式使用酒馆当前模型和 `generateRaw`；独立模式通过酒馆 Custom API 服务端代理发送请求，**不会修改主 API 设置**。
- **附加参数**：折叠收纳「包含主体参数 / 排除主体参数 / 包含请求标头」。支持每行 `名称: 值`，包含主体参数也接受 JSON 对象；插件不替你填写任何服务商标头。
- **自定义提示词**：楼层摘要及物品／场景／角色联合提取、L1 首次总结、L2 二次总结、L3+ 高层总结各自可查看全文、编辑或恢复默认。联合提取只调用一次模型，避免不同实体状态相互矛盾。
- **向量记忆**：默认模型 **`BAAI/bge-m3`**（适合中文及多语言剧情检索）。独立配置 Embedding API URL／Key／模型，与酒馆 API 和酒馆密钥完全分离。浏览器直接调用 OpenAI 兼容 `/embeddings` 接口；向量索引缓存在本浏览器 IndexedDB，可依据聊天摘要重建。**要求提供商允许浏览器跨域请求（CORS）**。向量 Key 存在自己的扩展设置内，请勿公开分享含配置的备份。
- **记忆注入**：可选择注入摘要、物品、场景、角色与向量召回结果，并提供内容预览。

## 摘要设置

- 默认温度 `0`，最大输出 Tokens 默认 `8192`，可配置到 `65536`（最终上限由模型决定，部分模型不接受温度 0）。
- **自动摘要**默认关闭；**延迟自动摘要**默认 `3`，表示最新 3 条 AI 回复不会自动摘要，第四条 AI 回复到来后才开始整理更早楼层。按 AI 楼计算，不包含用户消息。手动批量补摘不受延迟限制。
- **摘要成功后自动隐藏楼层**默认关闭。开启后，仅排除摘要有效、已离开保留窗口的 AI 楼层及其连续关联用户输入；不删除原始聊天。**保留最近正文**默认 `3`，与自动摘要延迟数取较大者保护最新剧情。若原文超过单次摘要输入上限，不会自动隐藏，以免遗漏被截断的内容。
- 自动隐藏采用 SillyTavern `/hide` 同等的 `is_system` 消息可见性机制，编辑用户内容或切换 AI swipe 后，旧摘要会失效，并尝试恢复被本插件隐藏的关联消息。关闭自动隐藏不会自动恢复此前已隐藏的消息；如需手动恢复，在酒馆使用 `/unhide`。
- 分层压缩默认：L0→L1 阈值 `12`，保留最近 `3` 条未压缩 L0 摘要；L1→L2 阈值 `6`，高层阈值 `3`。阈值设为 `0` 可关闭对应压缩层级。

## 时间与摘要修改

- 新生成的故事时间使用 `YYYY/MM/DD · HH:mm` 或 `YYYY/MM/DD · HH:mm–HH:mm`；只有时刻或时间未知时不虚构日期。旧记录在时间线显示时也尝试规范格式，不改写原始聊天文本。
- 摘要和分层总结卡片只负责阅读：展开后显示**一份摘要正文**，底部有「编辑」「删除」按钮。点击编辑弹出独立居中窗口（L0 可编辑正文、故事时间、地点；L1+ 只编辑正文）；点击删除弹出单独的二次确认窗口，明确影响范围。按 Esc、点击外部遮罩或「取消」只关闭当前操作窗口，不关闭整个剧情记忆插件，未保存的草稿不会改动记忆。
- L0 摘要支持修改正文、故事时间与地点；L1/L2/L3+ 总结支持修改正文。修改时会使依赖旧内容的高层总结失效，但不会覆盖原始聊天。
- 删除生成的楼层摘要会同时撤销该楼层提取的物品、场景、人物、计划变化，保留原始聊天，并暂停对当前版本楼层的自动重新摘要。摘要页提供「重新摘要」入口；原剧情改变时可重新进入待摘要列表。
- 删除 L1+ 分层总结时保留下层素材，且避免同一批素材立即重复压缩。删除操作需确认。
- **恢复默认**：重置 Embedding 模型为 `BAAI/bge-m3`，保留向量 API 地址与密钥；摘要 API 的连接配置与模型照旧保留。旧版本曾保留向量模型，所以已经点击过旧版「恢复默认」的用户仍需使用新版按钮再次恢复。

## 配置示例

附加参数 → 包含主体参数：

```text
prefix: true
```

附加参数 → 排除主体参数：

```text
frequency_penalty
presence_penalty
```

附加参数 → 包含请求标头：

```text
x-opencode-session: sillytavern
```

以上标头只是普通格式示例，不会自动填写。Authorization、Cookie 等认证标头不能手动添加；独立摘要 API 自动使用该渠道填写的 Key。为了与柏宝书一样便捷，**独立摘要 Key 会保存在 SillyTavern 扩展设置中**，请勿公开导出包含扩展设置的备份。

## 使用提示

自动摘要默认关闭。首次使用建议先在测试聊天验证副 API 响应格式、记忆注入与向量功能，再对长期聊天启用批量整理。

自动隐藏开启前，记忆注入与未隐藏正文可能存在重复；建议先检查「注入预览」，再在测试聊天启用。自动隐藏需要酒馆提供保存聊天的接口，实际效果仍需在目标酒馆版本测试。上游内容拒绝不会通过反复重试绕过。
